**Como a aplicação foi estruturada?**
Para simplificar a organização do projeto, dividimos o site em partes menores: o cabeçalho da página, o calendário, as tarefas do dia, o resumo e o planejador semanal.
O cabeçalho contém o nome do projeto e a data atual; 
O calendário permite a visualização dos meses do ano; 
A seção de tarefas do dia inclui um formulário para adição de tarefas, permitindo a entrada do título da tarefa, sua descrição, data e hora em que ela deve estar pronta e opções de prioridade (alta, normal e baixa), assim como a escolha de um emoji para representação gráfica. Além disso, o usuário recebe a opção de editar ou excluir um projeto existente; 
O resumo mostra o número total de tarefas criadas durante o uso do site, o número de tarefas concluídas e as tarefas pendentes; 
E, por fim, o planejador semanal permite visualização dos dias da semana e as tarefas de cada dia. Além disso, esta parte inclui a opção de mudar a cor tema do site.

**Quais tecnologias foram usadas e por que?**
O Visual Studio Code foi escolhido como a IDE usada para a criação do programa graças à familiaridade dos integrantes do grupo com sua operação. Além disso, foram utilizadas IAs como o Gemini, o ChatGPT e o Claude para auxiliar na elaboração da estrutura dos códigos, identificar e corrigir bugs e melhorar a implementação dos eventos e suas funcionalidades, assim como para a formação do esboço geral do projeto e para ajudar nas pesquisas relacionadas às suas necessidades. Cada integrante usou seu próprio computador ou notebook para o desenvolvimento do projeto.

**Quais alternativas poderiam ter sido utilizadas?**
Outra opção de IDE seria o WebStorm, que possui como benefício uma extensa lista de ferramentas para facilitar o desenvolvimento de aplicações web, mas não foi escolhido para a criação do projeto por se tratar de um software pago. Ele seria uma boa escolha caso a equipe tivesse a intenção de tornar o site em um projeto comercial.
